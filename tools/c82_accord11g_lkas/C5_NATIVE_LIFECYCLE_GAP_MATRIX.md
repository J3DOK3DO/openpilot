## Actual ingress and authority path

1. Honda CarState derives `vEgo` and `standstill` from CAN speed sources ([carstate.py:83](../../opendbc_repo/opendbc/car/honda/carstate.py#L83)). Honda Card clears its latch on non-Drive or low speed ([stock_intent.py:9](../../openpilot/starpilot/car/honda/stock_intent.py#L9), [stock_intent.py:38](../../openpilot/starpilot/car/honda/stock_intent.py#L38), [stock_intent.py:111](../../openpilot/starpilot/car/honda/stock_intent.py#L111)). These are host checks sharing CarState, not independent Panda speed sensing. Card validates native identity and session and updates intent ([card.py:657](../../openpilot/selfdrive/car/card.py#L657), [card.py:969](../../openpilot/selfdrive/car/card.py#L969)). SelfdriveD's `decide_axes` requires valid car state, driving gear, model readiness, and no lateral inhibit/fault ([runtime.py:174](../../openpilot/starpilot/aol/runtime.py#L174)); a missing native status can raise `controlsMismatch` ([selfdrived.py:2060](../../openpilot/selfdrive/selfdrived/selfdrived.py#L2060)). Controls' ordinary steer gate also uses host standstill ([controlsd.py:353](../../openpilot/selfdrive/controls/controlsd.py#L353)).
2. The production C++ pandad negotiator requires a zero-request acknowledgment for a changed session, mode or param ([aol_protocol.h:111](../../openpilot/selfdrive/pandad/aol_protocol.h#L111), [aol_protocol.h:158](../../openpilot/selfdrive/pandad/aol_protocol.h#L158)). Pandad writes the mask by Panda USB control `0xf5`, sets heartbeat, reads native status and reports the owner/session ([pandad.cc:488](../../openpilot/selfdrive/pandad/pandad.cc#L488), [panda.cc:195](../../openpilot/selfdrive/pandad/panda.cc#L195), [panda.cc:217](../../openpilot/selfdrive/pandad/panda.cc#L217)). A changed Panda owner resets the negotiator ([pandad.cc:493](../../openpilot/selfdrive/pandad/pandad.cc#L493)).
3. Panda stores host mask/timestamp and calls the Honda policy ([safety.h:63](../../opendbc_repo/opendbc/safety/safety.h#L63)); invalid RX, tick lag, and safety-mode reset clear the mask ([safety.h:178](../../opendbc_repo/opendbc/safety/safety.h#L178), [safety.h:370](../../opendbc_repo/opendbc/safety/safety.h#L370), [safety.h:512](../../opendbc_repo/opendbc/safety/safety.h#L512)). Native Honda MAIN, LKAS and normal cruise transitions create grants; Bosch 80/81 requires Drive and retires grants on non-Drive ([honda_stock_aol.h:190](../../opendbc_repo/opendbc/safety/modes/honda_stock_aol.h#L190), [honda_stock_aol.h:227](../../opendbc_repo/opendbc/safety/modes/honda_stock_aol.h#L227)). A valid current EPS/gear/main source, heartbeat and fresh request are needed for a request; MAIN, Drive, EPS and token gate permission ([honda_stock_aol.h:102](../../opendbc_repo/opendbc/safety/modes/honda_stock_aol.h#L102), [honda_stock_aol.h:117](../../opendbc_repo/opendbc/safety/modes/honda_stock_aol.h#L117), [honda_stock_aol.h:143](../../opendbc_repo/opendbc/safety/modes/honda_stock_aol.h#L143)). Nonzero `0xE4/0x194` steering is denied when lateral permission is absent ([honda.h:310](../../opendbc_repo/opendbc/safety/modes/honda.h#L310)).

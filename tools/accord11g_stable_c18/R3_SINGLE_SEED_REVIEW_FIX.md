# C18 R3 — single CAN seed delayed-frame correction

The R2 independent reviewer returned FAIL_SCOPED because a single matching Accord CAN frame in StarPilot's first 24 passive reads did not satisfy the two-source plausible topology threshold, and the generic OBD CAN2 mux scan began before the full 11G layout appeared in read 25. The new R3 passive *seed* check causes a bounded extension (at most 48 reads, deadline 0.65 seconds) for even one matching Honda candidate ID. After the observation, a single uncorroborated ID **does not authorize Honda selection**; it returns to ordinary generic discovery. Only corroborated multi-ID or full topology takes the bus0-only Honda FW path, with exact unique 11G FW identification and contradictory, absent or unknown FW held to MOCK.

Added production-level regression for one initial seed and complete Accord layout at read 25: requires zero OBD multiplexing; also verifies a lone uncorroborated ID still follows generic other-car discovery. This is an offline source safety improvement, NOT proof against arbitrarily delayed CAN beyond bounded discovery nor a substitute for real physical CAN2/panda safety qualification. No Panda safety watchdog, car actuation, OEM ACC or alpha-long changes.

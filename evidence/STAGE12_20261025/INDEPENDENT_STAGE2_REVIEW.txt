## Independent disposition

No CRITICAL finding within the strictly nondeployable, non-executing host-model scope. There are several MAJOR model-assurance gaps that prevent calling Stage 2 fully qualified.

### MAJOR

- **Health attestations can silently disagree.** The external health decision and protected-authority attestation are validated independently, but their startup measurements are never compared ([rc3_stage2_supervisor.py:882](/mnt/commadrive/g8-f12-rc3-stage12-qualification-20261025/tools/g8_release/rc3_stage2_supervisor.py:882), [g8_protected_authority.py:604](/mnt/commadrive/g8-f12-rc3-stage12-qualification-20261025/tools/g8_release/g8_protected_authority.py:604)). The tests explicitly use `"d"*64` for `HealthDecision.measurement_sha256` and `"e"*64` for the protected `boot_measurement`, then accept health successfully ([test_rc3_stage2_supervisor.py:230](/mnt/commadrive/g8-f12-rc3-stage12-qualification-20261025/tools/g8_release/tests/test_rc3_stage2_supervisor.py:230), [test_rc3_stage2_supervisor.py:237](/mnt/commadrive/g8-f12-rc3-stage12-qualification-20261025/tools/g8_release/tests/test_rc3_stage2_supervisor.py:237), [test_rc3_stage2_supervisor.py:511](/mnt/commadrive/g8-f12-rc3-stage12-qualification-20261025/tools/g8_release/tests/test_rc3_stage2_supervisor.py:511)). This contradicts the exact health-context requirement in [STAGE2_OS_SYSTEMD_INTEGRATION_CONTRACT.md:44](/mnt/commadrive/g8-f12-rc3-stage12-qualification-20261025/evidence/STAGE12_20261025/STAGE2_OS_SYSTEMD_INTEGRATION_CONTRACT.md:44).

- **An idempotent launcher decision can outlive protected authority.** Once local phase is `ATTEMPT_CONSUMED`, an exact repeated request returns a cached launcher decision without consulting the authority ([rc3_stage2_supervisor.py:811](/mnt/commadrive/g8-f12-rc3-stage12-qualification-20261025/tools/g8_release/rc3_stage2_supervisor.py:811)). If the protected trial was externally canceled or revoked after the first response, the local journal can still return that decision. The corresponding test assumes authority state remains unchanged ([test_rc3_stage2_supervisor.py:407](/mnt/commadrive/g8-f12-rc3-stage12-qualification-20261025/tools/g8_release/tests/test_rc3_stage2_supervisor.py:407)). This weakens the claim that the protected authority is the sole authorization source.

- **Protected grants do not bind the full launch context.** `BootGrant` contains only disposition, candidate, and attempt counts ([g8_protected_authority.py:169](/mnt/commadrive/g8-f12-rc3-stage12-qualification-20261025/tools/g8_release/g8_protected_authority.py:169)). OS identity, device identity, physical gate, owner context, request ID, and attempt nonce remain in the ordinary journal, and the signed gate envelope itself is discarded after verification. By contrast, the prior F6 model binds a signed grant to boot, policy, OS slot, candidate, and immutable snapshot ([g8_f6_early_boot_boundary.py:625](/mnt/commadrive/g8-f12-rc3-stage12-qualification-20261025/tools/g8_release/g8_f6_early_boot_boundary.py:625)). Therefore [STAGE2_IMPLEMENTATION_REPORT.md:34](/mnt/commadrive/g8-f12-rc3-stage12-qualification-20261025/evidence/STAGE12_20261025/STAGE2_IMPLEMENTATION_REPORT.md:34) overstates end-to-end strict binding.

- **Journal-tamper coverage tests only inconsistent tampering.** The test changes `trial.manifest_sha256` without changing the duplicate gate record, so equality validation predictably catches it ([test_rc3_stage2_supervisor.py:484](/mnt/commadrive/g8-f12-rc3-stage12-qualification-20261025/tools/g8_release/tests/test_rc3_stage2_supervisor.py:484)). Coordinated canonical changes to gate/OS/device/request fields are not authenticated again on load, and `_validate_state()` does not rebind them to the live supervisor instance ([rc3_stage2_supervisor.py:646](/mnt/commadrive/g8-f12-rc3-stage12-qualification-20261025/tools/g8_release/rc3_stage2_supervisor.py:646)). The suite therefore does not establish replay or hostile-writer resistance for the host journal.

### MINOR

- **Crash qualification is partial.** Only the post-consumption authority crash is exercised. Preauthorization, post-health, promotion, journal prewrite/replace/commit, and ambiguous cancellation boundaries are untested. Preauthorization deliberately becomes an unrecoverable local HOLD with an active protected trial requiring unspecified external reconciliation ([rc3_stage2_supervisor.py:996](/mnt/commadrive/g8-f12-rc3-stage12-qualification-20261025/tools/g8_release/rc3_stage2_supervisor.py:996)). This is fail-safe but not qualified recovery.

- **Directory/symlink hardening is incomplete.** `state_root` is resolved before `is_symlink()` is checked, so the check cannot identify a symlink supplied as the original path; pre-existing directory ownership/mode is not checked, and the lock is opened without `O_NOFOLLOW` ([rc3_stage2_supervisor.py:402](/mnt/commadrive/g8-f12-rc3-stage12-qualification-20261025/tools/g8_release/rc3_stage2_supervisor.py:402), [rc3_stage2_supervisor.py:550](/mnt/commadrive/g8-f12-rc3-stage12-qualification-20261025/tools/g8_release/rc3_stage2_supervisor.py:550)). The readiness-gate evidence reader has materially stronger component-wise `openat/O_NOFOLLOW` handling ([rc3_hardware_readiness_gate.py:146](/mnt/commadrive/g8-f12-rc3-stage12-qualification-20261025/tools/g8_release/rc3_hardware_readiness_gate.py:146)).

- **Stage 1 “closure pass” is only a name-resolution inventory.** Any SONAME present in the captured `ldconfig` cache is treated as resolved without inspecting or hashing the target ELF or its exported symbol versions; absolute RPATH entries are skipped ([stage1_linker_closure.py:29](/mnt/commadrive/g8-f12-rc3-stage12-qualification-20261025/evidence/STAGE12_20261025/stage1_linker_closure.py:29), [stage1_linker_closure.py:49](/mnt/commadrive/g8-f12-rc3-stage12-qualification-20261025/evidence/STAGE12_20261025/stage1_linker_closure.py:49)). `STAGE1_NATIVE_SYMBOL_VERSION_REPORT.json` also lacks a retained generator, command, or device-library digests. The evidence correctly says runtime compatibility is unproven, so these are not installation blockers beyond the already-active HOLD, but “closure pass” must not be read as ABI/runtime qualification. The Stage 1 collection script itself used SSH ([stage1_static_abi_audit.py:56](/mnt/commadrive/g8-f12-rc3-stage12-qualification-20261025/evidence/STAGE12_20261025/stage1_static_abi_audit.py:56)); I did not reproduce that device evidence.

### VERIFIED limitations

- OS and application identities are syntactically separated, and application candidates cannot be passed as `OsSlot`.
- Retry consumption is monotone within `MockProtectedAuthority`, with a hard Stage 2 limit of three, but both authority and journal are ordinary-file simulations—not rollback-resistant storage.
- No process, launcher, device, installation, boot-control, Panda, or CAN action exists in the new module. Failure paths generally HOLD or select approved recovery metadata; no unsafe executable fallback was found.
- Immutable recovery is only an externally asserted identity/hash. Stage 2 does not integrate F6’s signed consumed grant or immutable pinned descriptor.
- The custom readiness-gate Ed25519 code remains unsuitable for production, as the evidence correctly records.
- Supplied hashes verified. The isolated host-only suite reran successfully: **28 passed in 0.27s**.
